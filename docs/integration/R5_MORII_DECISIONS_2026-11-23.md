按 [R4 一次性验收指南](../RUNTIME_R4_ACCEPTANCE_2026-11-19.md)用最新候选走一遍（候选号以指南开头为准）。第一次真实写入（修改记录、登记 Agent）前，先让 Memory 会话确认库仍是 seq 440，并且有一份校验过的导出。

## 3. 外壳与安装（门槛 G）

用候选安装包：全新或升级安装、托盘（关闭收进托盘、重新打开、退出）、全局热键 Quick Search、登录启动（只出现托盘、不自动开库）、卸载。安装会替换本机旧版本，时间由你定。

## 4. ChatGPT 实连

等下月买好域名。Memory 的远程服务要部署到 VPS，所需授权和信息由 Memory 会话提供；部署后 Settings 的连接器状态才会从“未连接”变化。
