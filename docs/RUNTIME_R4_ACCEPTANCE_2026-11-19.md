# R4 一次性验收指南（2026-11-19）

这是路线 R4 的最终验收：Runtime 原有界面全部接到你的真实库后，由你一次走完。它取代 [R3 只读验收](RUNTIME_MORII_READONLY_ACCEPTANCE_2026-11-17.md)里尚未填写的人工回执；R3 的步骤并入下面的第 1、3、4、9 步。

## 用哪个程序

候选从 Runtime main 构建，内嵌 Memory pin `f9ac21d`（全历史读取），见[候选记录](validation/R4-5-candidate-2026-11-19.md)（候选 `884c015`，含路径与 SHA-256；旧候选 `218df03` 作废）。

- **免安装验收（推荐先做）**：候选目录里相邻的 `enouia-desktop.exe` 与 `WebView2Loader.dll` 一起使用，不改动已安装的旧版本。
- **安装、升级、托盘、热键、登录启动**：用同一候选的安装包，单独记在文末第二张表。安装会替换本机旧版本，按你的安排做。

用原登记的 Windows 账户，以只读参数启动（参数由你保管，不写进公开仓库）：

```powershell
& "<候选目录>\enouia-desktop.exe" --memory-owner-readonly --memory-owner-home "<登记 home>" --memory-owner-operation "<登记 operation>"
```

开始前确认：没有别的 Enouia 程序或 Memory 导出 / 迁移正在占用这个库。2026-11-19 Memory 已把数据区迁到你指定的统一目录：home 换成迁移后的新路径，operation 不变；旧 home 参数现在会被拒绝。

## 读取窗口

已解决：Memory ADR-MEM-153（pin `f9ac21d`）让登记入口按全部历史策略授权读取，11-24 形成策略到期后界面仍能读到全部记录；删除、撤回、遗忘屏障和敏感度上限照常生效。旧候选 `218df03` 没有这项改动，到期后会几乎读不到记录，请用新候选。

## 走查（每步记 通过 / 不通过 / 阻塞）

反馈只写界面现象、错误码和时间，不要粘贴记录正文或完整路径。

1. **启动与状态。** 顶栏写“已登记库已打开 · 已登记库 · 仅确认后写入”。Settings 只给“打开原生记忆目录”，没有新建 / 打开库或模型配置。失败时不会转开别的库。
2. **Home。** 四条注记显示真实读数：记录总数（已采用 / 暂存）、最近一次形成事件、已捕获对话数；Context 注记指向召回预览。没有编造的提交点或时间迹线（只读库本来没有）。
3. **记忆目录。** 默认选中“原生记忆目录”，每页最多 50 条，显示“X 条显示 · Y 条匹配”。用筛选框（种类、知识状态、采用状态、注意力、对象、项目）筛一次，计数应随之变化；再清空。搜索一个你知道的词。
4. **详情与来源。** 点一条记录：右侧显示发生 / 有效 / 学到时间、保密级别、涉及对象、为什么形成、修订历史。点“读取引文来源”，摘录应与引文一致。被纠正过的那条记录应显示第 2 版。
5. **时间。** 左栏“时间”：按月的格子，只在有记录的月份出现数字；顶部说明多少条没有事件时间。切换“学到时间 / 来源捕获时间”轴，点一个月份，下方列出该月记录，点开可读详情。
6. **关联。** 左栏“关联”：读完全部记录后列出关系类型（目前主要是“同一段对话”）、关联最多的记录（显示标题）。点一条看相关记录。页面说明语义近邻暂不可用。新候选另有“共同词语建议”：用了几个相同词语的记录成对列出，附共同词语和得分，并说明只是建议、不是记录下的关系；点一条记录时右侧也列出它的共同词语建议。
7. **形成。** 左栏“形成”：系统做过的事件，最新在前，可按类型筛选、显示更早的事件；点事件看记录和是否有相互冲突的记录。
8. **召回与 Context。** 左栏“召回”：输入一个提示，选范围，点“预览召回”：列出入选记录（得分与理由）、其余为什么没选、字节数和生成的上下文。顶部导航“Context”是同一预览，默认展开生成的上下文。两处都说明不保存、不登记 Agent。
9. **Sessions。** 列出已捕获的对话（标题、时间、平台、轮次数）；点开读取轮次正文，说明只含已捕获的轮次。
10. **Runtime Inspector。** Memory Core 一栏显示读取能力、快照（提交 / 纪元）、水位线、可读记录数、采用与注意力计数、已捕获对话数、最近事件。
11. **Quick Search。** 用热键（默认 Ctrl+Alt+Q）打开小窗，搜一个词：结果来自已登记库，显示标题与片段和匹配数；Esc 关闭并清空。
12. **语言。** Settings 切到中文、日文再切回，各页文字切换、已读内容不重新读取。
14. **修改（门槛 A）。** 第一次真实写入前，请 Memory 会话确认库仍是 seq 440（它已有一份用新工具校验过的导出），库若变了先重新导出。然后在一条记录的详情里打开“修改这条记录”，选一种（建议先“保护”这类可再调整的），点“预览修改”看计划（受影响的记录数、原始来源保留、无物理删除），再点“确认并写入”。成功后列表按新状态重新读取，“形成”里出现这次事件。结果未知时只点“查询结果”，不要重复操作。
    注意：库里写入第一条新式修改后，用旧版本程序（`884c015` 及更早）将打不开这个库，请只用包含门槛 A 的新候选。
15. **本机 Agent 授权（门槛 D）。** Settings 的“本机 Agent”列出 Claude Code 和 Codex，初始为“未登记”，并说明 MCP 连接暂时还不能接通。点 Claude Code 的“登记…”，看计划（上限“个人”、90 天、允许请求、策略与来源条数），点“确认并写入”后显示“已登记 · 有效至…”，并出现“续期 90 天…”“更新来源范围…”“撤销…”。登记是真实写入，写前同样请 Memory 确认库状态与导出。
16. **Agent 请求队列（D2）。** Settings 的“Agent 请求”显示待处理 / 已跳过 / 已处理的条数。Agent 接通 MCP 之前这里是空的；接通后让 Claude Code 对一条记录提一次纠正请求，队列里应出现它引用的你的原话和“它提出的纠正（未经核实）”。点“查看…”只打开那一种改动，内容预填且可改；“预览修改”→“确认并写入”后，请求离开队列。“跳过”只在本机记下，库不变，可在“显示已跳过”里放回队列。
17. **值得回看。** 记忆目录左栏“值得回看”：默认往后看 30 天，列出快要归档或有效期快要结束的记录（可能为 0 条），换成 90 天再看一次。下方“注意力时间表”列出未来 90 天的淡出 / 归档时刻，说明这些时刻是推算的、不是记录下的，并写出受保护条数。点一条记录能读详情。页面写明建议只看时间、不评判对错。
13. **锁定与重开。** 记忆目录里点“锁定已登记的库”：各页数据撤下、顶栏显示已关闭、没有解锁按钮。退出 Runtime，再用同样参数启动，应是同一个库、同样的计数。右上角关闭只是收进托盘，不等于释放库。

遇到“无法为当前账户认证这个已登记的库”时，保留参数与时间，交给 Memory 会话在同一账户下核对，不要改库文件或换操作编号。
