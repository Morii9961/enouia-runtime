# 反 slop

slop 的来源不是「模型不会设计」，而是没做决定时它选最大概率的那个。这一份列出最常见的条件反射，并给三个检验。

## 1. 旧 slop：模型的条件反射

出现在你的方案里时，先停一下问「这是我选的，还是我没选？」

**颜色与材质**
- 紫到蓝、蓝到粉的渐变；渐变文字；发光、光斑、极光背景
- 深蓝灰（#0f172a 一带）加青色强调的「暗色模式」
- 毛玻璃（backdrop-blur）铺满页面；卡片 + 柔阴影 + 大圆角（16–24px）当万能容器
- 全站统一的同一个圆角值

**字体**
- Inter / Roboto / Arial / 系统字体直接当设计字体
- Space Grotesk（现在已经是 slop 的代名词）
- 标题和正文是同一个字体同一个字重，只差字号

**结构**
- 居中大标题 + 副标题 + 两个按钮的首屏
- 四个等宽 KPI 卡排在最上面（默认的后台开头）
- 三栏「特性卡片」
- 左侧栏 + 顶栏 + 卡片网格，不加思考地用

**细节**
- emoji 当图标；Lucide 图标放进彩色圆角方块里
- 默认图表库的外观（配色、网格线、tooltip 样式）
- `transition: all .3s ease`；hover 时 `translateY(-2px)` 加阴影
- 到处都是骨架屏闪光
- 「Welcome back 👋」、「John Doe」、「12,345」、「+12.5%」、lorem ipsum

## 2. 新 slop：反 AI 之后的新套路

「避开了旧 slop」不等于有设计。下面是被用烂的「高级感」：

- 米色纸底 + 衬线大标题 + 小号大写字距标签（所谓 editorial 的戏服）
- 黑底 + 荧光黄绿强调
- 伪粗野主义：粗黑边 + 4px 4px 的硬阴影
- 全站等宽字体 + `// 注释` 式文案（开发者 cosplay）
- 大号编号「01 / 02 / 03」当装饰
- 手写体到处点缀
- 全屏颗粒（grain）蒙层
- 只是「白底黑字大标题」的 Swiss

**这两份都不是禁令。** 只要你能用一句话说出「因为概念需要它，所以用」，就可以用。说不出来，就是反射。

## 3. 三个检验

**① 换牌测试。** 遮住产品名，换成别的产品、别的数据。设计还成立吗？成立，说明它没有属于自己的东西，只是模板。把「还认得出这是它」的三处写进 `DIRECTION.md`。

**② 首个念头弃置。** 每遇到一个设计问题（标题用什么字、主色用什么、总览怎么排），先把你第一个答案写下来，然后划掉，想第二个、第三个，再选。第一个答案几乎总是最大概率的那个。

**③ 「模板不会做」的决定。** 每个方向必须列出至少 3 个。例子：
- 数字出血，被视口边缘切掉一半。
- 筛选器是一排拨杆，不是下拉框。
- 加载状态是「逐行打印」，不是转圈。
- 状态用印章，不用彩色小圆点。
- 图表里没有坐标轴，数值直接标在线上。

如果列不出三个，这个方向还没设计完。

## 4. 「克制」不是借口

反 slop 不等于全部做成安静的米白。克制是一种选择，要和大胆的选择一样具体：克制的方向要在**比例、留白、字号反差、对齐**上下功夫，而不是什么都不做。一个安静的方向也必须通过「模板不会做」检验。
