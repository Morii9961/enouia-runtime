# R5：Home 记录纸用真实时间画线（2026-11-24）

Morii 问：“Runtime 首页的折线图还没正常显示”。查下来，登记模式的 Home 只有形成事件的标记，故意没画线。可见范围固定在最近 4 天，而真实库最近 4 天什么都没有，所以那块是空的。窗口顶上的记录带写着“未载入记录带 · 已登记库”，时间小地图也关着，没法挪到有记录的日子。

## 真实库里有哪些时间（只读探查）

用候选 `7021984` 只读读取，CURRENT 前后均为 440：

- 已捕获的对话 399 段，全部来自 ChatGPT，开始和结束时间都是精确时刻，从 2024-11 到 2026-11-09。最近六周有 121 段、528 个轮次，每个轮次都带 `occurred_at`；逐段读取轮次共用 1.3 秒。
- Memory 写入：11-17 形成 3 条，11-18 形成 348 条（导入），11-19 纠正 1 次。
- 记录按“发生时间”分布在 2024-10 到 2026-11，另有 199 条没有事件时间；按“学到时间”和“来源捕获时间”全部集中在 11-17/18。

设计稿里，Home 的那条线是“对话强度”：Morii 说话时笔抬起来，两次对话之间落回去；标记是 Memory 的写入。真实库正好有这两种记录下来的时间，所以改成按设计画。

## 改动

- **线**：最近六周里已捕获对话轮次的记录时间（`occurred_at`），每小时取一个点，用 3 小时的高斯平滑计数。没有轮次的地方线落在底线，不在记录之间补点。没有 `occurred_at` 的轮次不计入，因为捕获时间不是说话的时间。
- **标记**：形成（已采用为实心，暂存为空心）和纠正，同一小时、同一种类合成一个标记，悬停可看次数。
- **笔尖与“I'm here.”**：笔尖画在现在的位置；现在不在画面里时，“I'm here.”变淡。
- **画面**：一次显示两周，时间小地图覆盖六周，每天一根柱，表示当天的轮次数，Memory 写入画成刻度。如果最近两周没有轮次，打开时显示最近一次有轮次的那两周，“Now”按钮回到今天。
- **注记引线**：“形成”连到最近一次写入，“Sessions”连到最近一个轮次（都在画面里时才画）。Sessions 注记写出最近一轮的日期。
- **记录带**：其他页面顶上画同一画面的线和标记。读取中或读取失败时，记录带照旧显示斜线，并写明原因。
- 数据在状态层读取一次，按目录范围缓存，Home 和记录带共用，库有新写入后重新读取。只用已有的只读目录操作（`conversations`、`conversation_detail`、`activity`），不写库。

## 顺带更正：Sessions 的“分段”

[#249](R5-chatgpt-segments-2026-11-24.md) 按原始对话 ID 合并显示。真实库里同一个原始 ID 下就有 33 段“Enouia#1”，都没有 `#pol_` 后缀：这是导入时把一段很长的 ChatGPT 对话拆成了几段，不是捕获窗口轮换造成的。合并本身没错，但原来的文案“在之后的捕获窗口里接着记下”说错了原因，现在改为“同一段平台对话的后续部分”。详情页写“已读入的第 n 段，共 m 段（原始对话 ID 相同）”，不再说后一段不链接到前面的轮次。真实库截图是在改文案之前拍的。

## 边界

- 线只表示已捕获轮次的记录时间，不代表全部对话。Runtime 没有捕获的平台对话不在线上。
- 这一片没有构建安装候选；`7021984` 的 Home 仍是旧的只画标记的样子。合并后从 main 出新候选，供周末验收使用。
