# UI v2 W7 · OS 热键与 Quick Search 验证

日期：2026-10-29。代码基线 main `ca704d772311f38ea3882acc9bc5ddc646e2c5da`（PR #109），分支 `codex/ui-v2-w7-hotkey-smoke`。本片只改原生 smoke 的前置条件、保护和诊断，不改应用、默认热键、原生命令或 Memory pin。

## 改动

- `--quick-only` 通过现有 Settings 语言按钮选择英文，再回首页；主窗口与 overlay 等待共享语言生效，保留应用的三语 accessible names。
- 开库与第二进程拒绝开库的前置条件读取真实 `workspace_status.vault.state`，不依赖 UI v2 转为大写后的标题文字。
- 先检查测试进程确实注册 `Ctrl+Alt+Q`；未注册即停止。保留前台 PID 校验，只将其有界等待从 5 秒延至 30 秒；子进程总超时 45 秒。不会向其他前台进程发送按键。
- focused 模式只接受系统临时目录下 `enouia-runtime-quick-…` 的标记 fixture、固定 `vault` 子目录及非符号链接路径，且要求空库。标记内容为 `Runtime Quick Search synthetic fixture v1\n`。
- 增加两项 overlay 对托盘/窗口文字命令的拒绝检查；失败时记录两个窗口的焦点与 native 状态。主进程退出后，再用新 profile 验证热键释放并可重新注册。
