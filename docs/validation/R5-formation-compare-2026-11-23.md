# R5 A1–A3：修订对照、冲突对照与暂存假说（2026-11-23）

[R5 清单](../integration/R5_SURFACE_GAPS_2026-11-23.md)第一类的前三项。pin 不变（Memory `512ad0c`），只改 Runtime 界面，读取都用已有的只读端口。

## 改动

- **修订对照（A1）**：记录详情有两个以上修订时，出现“修订对照”。选较早、较晚两个修订，经 `revision_diff`（Memory 结构化修订差异）列出不同的字段；文本字段用最长相同前后缀标出字面差异，其他字段原样显示。页面说明只是字面差异，不评判含义。
- **冲突对照（A2）**：形成工作区选中事件后，若该记录在冲突组里，冲突双方并排显示标题、正文（标出字面差异）、知识与采用状态，并可打开任一条；不给“解决”动作，说明学到先后不决定真假。
- **暂存假说（A3）**：形成工作区新增“暂存假说”切换，按 `knowledge = hypothesis` 分页列出，附采用状态、形成理由、ChatGPT 提取标记和模型说明（标明不是事实）；点开读详情。
- `RevisionDiff` 类型与 `revision_diff` 视图读取；新字段名的三语翻译（“判 / 二 / 属 / 帰 / 強 / 番”不在字形子集，已改写）。
