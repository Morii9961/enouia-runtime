# UI v2 #24 星图成本定位

基线：`142e191`。本片只增加独立浏览器诊断工具及测量记录，没有更改产品绘制。遵循先复现、单变量对照再决定修复的顺序。

从 `apps/desktop` 运行：

```powershell
node e2e/starmap-diagnostics.mjs 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe' target/starmap-diagnostics
```

工具启动自己的 Vite、本机回环调试端口和新建 Edge profile；只访问虚构星图。退出关闭自己的浏览器与服务器，临时 profile/日志保留在忽略的 target。不会连接用户浏览器、原生 Runtime、Vault 或 Provider。初次沙箱拒绝回环连接（EACCES）；之后经自动权限审查允许独立诊断。最初控件选择器有误，按实际 aria-label 修正后完成八组。

环境：独立无头 Edge `156.0.4314.58`，1440×900 逻辑视口，DPR 1.5；画布 1530×1002 像素。每组预热 1.2 秒、采样 6 秒，无隐藏/零样本。完整结果见[数据](UI-v2-starmap-cost-2026-11-03.json)。

| 场景 | draw 间隔中位 ms | 脚本 draw 中位 ms |
| --- | ---: | ---: |
| 球体 200，原样 | 34.9 | 0.2 |
| 球体 5,000，原样 | 138.5 | 8.0 |
| 球体 5,000，临时略过光晕 | 127.4 | 2.5 |
| 球体 5,000，略过光晕及 lighter 切换 | 129.3 | 2.5 |
| 球体 5,000，恢复原样 | 138.8 | 8.4 |
| 聚类 5,000，原样 | 99.5 | 1.1 |
| 聚类 5,000，临时略过主题连线 | 35.2 | 1.1 |
| 聚类 5,000，恢复原样 | 102.8 | 1.1 |

结论限于本环境：光晕解释部分脚本开销，但不足以解释大部分 draw 间隔；聚类的主题连线明显影响整条绘制链路。不能仅凭这些数据把根因细化为虚线算法或某个 GPU 阶段。下一步可对照保留全部连线但替换虚线绘制路径的探针，并验证像素；不直接删除连线或改变视觉。

这些间隔由 draw 完成时间记录，不是屏幕实际呈现时间；无头 Edge 不等于 WebView2 或 Morii 验收。探针会临时改变诊断页面像素，未交付为产品优化，#24 保持未关闭。本片实际完成八组浏览器诊断、`node --check` 与 `git diff --check`，没有重跑产品测试或构建。
