# R5 A4–A5：时间工作区的月 → 日与覆盖日历（2026-11-23）

[R5 清单](../integration/R5_SURFACE_GAPS_2026-11-23.md)第一类第 4、5 项。pin 不变（Memory `512ad0c`），只改 Runtime 界面。

## 改动

- 选中一个月后，按同一时间轴读取该月的日粒度时间桶（`time_buckets`，granularity day），列出“按日覆盖”表：每天一列，三行分别是捕获的来源（材料）、暂存、采用。Memory 的时间桶本来就分别给出这三项计数，一次读取即可，不用分层多次请求。
- 有记录的日子可以点开，下方列表改为当天的记录（时间窗口取该日），也可以回到整个月。
- 没有材料或记录的格子显示一个点，并说明这不等于那天什么也没发生；捕获的来源是材料，不是记录。
- 未知时间的条数照旧在月表上方说明，不补日期。
