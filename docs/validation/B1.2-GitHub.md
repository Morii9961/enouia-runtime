# B1.2 GitHub collector adapter validation

Date: 2026-09-27. Scope: one GitHub adapter using the `ProcessRunner` port and strict normalization of a contribution calendar response. B1.2 as a whole remains open for Codex and Claude adapters.

The adapter uses a configured absolute `gh` executable and login, with no repository working directory or copied credential. It sends one `gh api graphql` request with string variables for the explicit 365-day calendar window (`Shanghai end date - 364 days` through end), matching the legacy producer's date labels and UTC query endpoints. Timeout is 40 seconds and the combined stdout/stderr output bound is 4 MiB. Cancellation aborts the candidate run instead of manufacturing a failed source. Failed process or malformed response becomes a GitHub-only failed attempt; raw stderr never enters the returned attempt.

The synthetic `github-calendar-v1.json` includes explicit zero and private sentinel fields. Fake-runner tests check the arguments, timeout, bound, privacy projection, GraphQL errors, empty/malformed calendars, impossible/duplicate dates, invalid/unsafe counts, nonzero exit, invalid JSON, oversized output, missing executable configuration, and cancellation. The contract normalizer checks the full report before the B1.1 merge applies acquisition filtering.

The request shape was checked against [GitHub's ContributionsCollection and ContributionCalendar reference](https://docs.github.com/en/graphql/reference/users) and the [`gh api` manual](https://cli.github.com/manual/gh_api). The existing Moriium collector's query and date-window calculation were inspected read-only during development; this crate has no build-time or runtime Moriium dependency.

The installed GitHub CLI reported version 2.97.0. A separate, read-only authenticated `viewer { login }` GraphQL call succeeded on this machine. Neither identity nor token was printed or stored. This establishes CLI/auth/GraphQL capability, not the configured migration account or a live contribution-calendar match; those need B1/B4 acceptance.
