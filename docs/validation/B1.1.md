# B1.1 pure Activity merge validation

Date: 2026-09-27. Scope: the side-effect-free `enouia-activity` merge and its contract time helpers. This is a feature-level validation, not completion of all B1 collectors or any production migration.

The merge accepts a prior normalized ActivityData, exactly one attempt for each of GitHub/Codex/Claude, and a fixed clock. It returns the full merged ActivityData, three source outcomes, and local per-source deltas. Invalid individual successful snapshots retain only that source's old data; duplicate/missing attempts and clock regression block the whole transaction. The run end date is frozen from the shared attempt timestamp in the Shanghai calendar. The AI floor admits new days from 2026-01-01 onward; GitHub has no merge-level floor. Neither rule removes an already known date.

The committed `source-attempts-v1.json` drives an integration test. Additional synthetic tests cover downward/upward replacement, missing-day retention, explicit zero, a source with no admissible days, future-day filtering, pre-floor AI days, safe-sum overflow after historical merge, invalid source literals/dates, duplicate attempt identities, and clock rollback. Existing contract tests still verify v1 wire normalization, privacy allowlists, public serialization bytes, and the Moriium-normalizer SHA-256 oracle.
