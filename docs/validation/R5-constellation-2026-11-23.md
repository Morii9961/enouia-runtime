# R5 A6：关联工作区的星座图（2026-11-23）

[R5 清单](../integration/R5_SURFACE_GAPS_2026-11-23.md)第一类第 6 项。pin 不变（Memory `512ad0c`），只改 Runtime 界面。

## 改动

- 关联工作区选中一条记录后，主列顶部画“星座”：选中记录居中，用 Memory 邻居投影（`neighbors`）里的相连记录环绕，最多 12 个，其余仍在右侧列表。
- 每个节点同样大小；每种关系一种线型（同一段对话实线、同一实体虚线、主题共现点划线、派生 / 回退带箭头、共同词语点线），每条线都写关系名，算法建议另标“建议”；附图例。节点可用鼠标或键盘（Enter / 空格）打开。
- 标题按宽度截断（中日文字符按两个单位计），关系名带底色描边，不压在线上。
