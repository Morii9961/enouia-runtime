# UI v2：兼容 Vault 演示回执和校验错误

基线 `a1e7e26`（#122，依赖 #121；三张既有 PR 仍为未合并草稿）。这是交接“有证据的文案 / 等待恢复审阅”的小片，不改变五工作区、Memory pin 或后端契约。

## 复现与改动

实际 App 兼容列表中，复制成功/失败、候选空白校验/批准成功、修订空白校验/修订成功六类反馈，在动作完成后切换中文和日文：修复前 **12 项语言显示失败**。记录、草稿、焦点和动作计数在失败复现中已经保持稳定。

原因是 App 在动作结束时把 `t()` 的结果存进 state；纯演示函数的五条校验错误也未标记翻译。现在受控提示以 `msg()` 保留原始键，在 `renderVals()` 用当前语言翻译。错误 guard 和英文错误原文保持，原始内容、候选身份/来源、历史修订、时间与 key 都不经过翻译。没有新抽象、依赖、重试或重复动作，也没有将演示变更当成后端提交。
