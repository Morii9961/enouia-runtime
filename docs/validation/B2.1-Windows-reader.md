# B2.1 Windows pinned generation reader

Date: 2026-09-27. Scope: read one existing Activity generation from disk. The reader requires an absolute existing root, reads `CURRENT` once in the exact `g-...` plus LF form, and loads only that named directory. It checks the directory and opened file handles for Windows reparse-point attributes, bounds individual file reads, then delegates every hash and semantic check to [pure generation validation](B2.1-generation-validation.md). A missing `CURRENT` is an explicit missing-state error, not an implicit bootstrap. A missing or corrupt selected generation fails; the reader never searches older generations.

The [Rust Windows metadata extension](https://doc.rust-lang.org/std/os/windows/fs/trait.MetadataExt.html) exposes file attributes, and [Microsoft's file-attribute constants](https://learn.microsoft.com/en-us/windows/win32/fileio/file-attribute-constants) define `FILE_ATTRIBUTE_REPARSE_POINT`. The reader opens file handles with `FILE_FLAG_OPEN_REPARSE_POINT` and checks the opened handle's attributes. Directory checks are path-based; a concurrent hostile replacement of the directory tree is not yet excluded by this read-only slice. The root allowlist, write-side path policy, staged generation commit, atomic `CURRENT` replacement, and power-loss evidence remain B2 gates.

Four synthetic disk tests cover a valid pinned generation, missing `CURRENT`, a missing or corrupt selected generation with a valid older generation present, invalid/path-like pointer bytes, missing generation files, and an oversized pointer. Archive, pending, manifest, sequence, and delivery reads have local size bounds; an archive over 64 MiB currently fails without deleting or truncating it. That bound must be reviewed against real migrated archive size before activation.

Checks: `cargo fmt --all -- --check`, `cargo test --workspace` (85 tests, including four reader tests), `cargo clippy --workspace --all-targets -- -D warnings`, and `git diff --check` passed offline with the installed Rust 1.98.1 GNU toolchain. No Activity archive, scheduler, upload, Memory/Context state, or Moriium checkout was changed.
