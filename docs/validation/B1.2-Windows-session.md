# B1.2 Windows JSON-lines process session

Date: 2026-09-27. Scope: the Windows platform implementation of the `JsonLineSession` port. It launches a caller-selected absolute executable with hidden, piped standard streams and a private Windows Job Object set to kill its process tree when the session is dropped. The Activity crate remains platform independent and owns the Codex protocol and data validation.

The session applies a lifetime deadline to reads and writes, polls cancellation during both, and caps cumulative stdout plus stderr bytes. It returns structured error categories without exposing raw process text, paths, or credentials. A bounded channel carries stdout lines; stderr is drained only for the byte limit. The test fixture is a synthetic PowerShell script under this repository and uses no account data.

Six Windows process tests cover a three-message pipe exchange, full Codex protocol through a real child into an explicit zero token attempt, read timeout and stderr overflow, rejection of a relative executable, a nonreading child that cannot trap a write past the deadline, and process termination when the session is dropped. The existing seven fake-session tests still cover protocol-specific error handling. The platform crate's only production dependency on another Runtime crate is `enouia-common`; `enouia-activity` is a test-only dependency for the end-to-end check.
