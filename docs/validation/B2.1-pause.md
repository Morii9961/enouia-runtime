# B2.1 persisted Activity pause

Date: 2026-09-28. Scope: a `paused` Boolean in the hashed `delivery.json` of an immutable Activity generation, updated under the existing Windows writer lock. Missing `paused` means false for compatible earlier generations; any non-Boolean value invalidates the generation.

The setter changes only `delivery.json`, keeps archive, high-water sequence, exact pending bytes and any publication receipt, and switches `CURRENT` through the normal generation writer. Repeating the current value is a no-op. Run start returns `Paused` before either collection or pending retry; restricted SSH and public observation return a paused outcome without launching a process or fetching public data. Unpausing resumes the original pending bytes or the next unused sequence.

Synthetic Windows tests cover pause/unpause across restart-readable generations, no sequence reservation on pause, preservation of a pending batch, rejected malformed pause state, and no SSH process launch while paused. The shared generation writer's crash-boundary tests apply to the pointer switch. This is local state behavior; no scheduler or UI is activated.
