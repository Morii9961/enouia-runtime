# B2.1 read-only Activity delivery overview

Date: 2026-09-28. Scope: read a sanitized local summary from the selected, audited Activity generation while holding the writer lock. The API reports pause state and, when a batch is pending, its sequence, exact-byte hash, age, and persisted retry disposition. Age is calculated from the durable batch `createdAt` at read time; it is not stored. A clock earlier than that creation time is rejected.

The overview returns no raw pending bytes, filesystem paths, process output, or credentials. It does not send, observe, acknowledge, or modify a generation. A caller still needs the separate run-start, transport, and public-observation decisions. Recovery audit runs before any state is returned, so a corrupt or conflicting generation fails closed.

The synthetic Windows test covers an empty initial overview, a persisted pending batch with retry and pause state, an age derived one hour later, and a regressed clock. The existing recovery tests cover malformed and conflicting generations. This is a local read API, not an activated UI or scheduler.
