# UI v2 冲突记忆读取与恢复文案

基线：`643b453`。候选中的冲突引用与当前记忆读取结果继续分开显示；补齐读取/重新读取按钮、失败恢复说明、当前修订及记录变化警告的中日文。当前读取不会被表述为已经解决冲突，保存内容与状态码保持原样。

实际验证：

- `candidate-conflict-focus` Happy DOM 场景：24 项断言通过。三语下保留当前记录、来源引用 r1 与当前 r2 的区分、纯文本、焦点；失败后保留同一个恢复按钮，不额外读取。原有重试、隐藏、改版及卸载的迟到结果/焦点保护通过。
- `candidate-conflict` 场景：10 项断言通过，包括读取拒绝、错误记忆身份、旧观察撤下和无写入。
- i18n / CJK 字体定向 Node 检查：11 通过；`npm run check`、根 Memory pin 检查、`git diff --check` 通过。

没有运行完整套件、构建、原生或人工验收，没有访问个人 Vault 或 Provider。首次字体检查发现一个新增字形，调整等义中文措辞后通过，字体资产未改动。
