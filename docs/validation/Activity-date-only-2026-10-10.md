# Date-only display precision

Date: 2026-10-10. Baseline: `b8c9e8f7d919b30023d91ba9b30a5170c7b5866f`. This changes the frontend display of already supported date-only metadata. The producer, IPC schema, collector timestamp admission, native adapter, dependencies and Memory revision are unchanged. J1/B4 remain partial; B5 is inactive.

Date-only observations were parsed as midnight UTC and displayed with a local clock time. They also acquired a specific elapsed-hour age, although the supplied observation specifies neither an hour nor a zone. The UI now retains the exact date and leaves the elapsed age unknown. Timestamps with explicit offsets retain their existing clock and age formatting, including the existing 90-minute threshold for switching from minutes to hours.

The [hashed proof](Activity-date-only/proof.json) records [16/16 native display checks](Activity-date-only/dates.json), against an [8/16 old-build baseline](Activity-date-only/before.json). Overview replies are explicitly modeled; healthy setup and reads use actual native IPC. The drill covers next trigger, retry, transport, publication, source observation and pending age, followed by explicit-offset timestamps. It blocks run/retry/pause requests, attempts none, and preserves saved choice, manifest and store bytes. Native screenshots were inspected: date-only labels contain no fabricated clock or hourly age.

The [62/62 frontend tests](Activity-date-only/tests.json) include date-only/offset rendering and deterministic age checks. The clock-only red test was 60/61; after correcting clock display, the age red test was 61/62 with `36 h ago` instead of an unknown age. An initial native observer expected an unknown-age separator that SourceCard intentionally omits, producing 15/16; correcting that expectation produced the final 16/16 without another product change. A test initially expected `1 h ago` for 60 minutes, but the existing formatter correctly uses `60 min ago`; the test expectation was corrected. The first 8/14 baseline, clock-only 14/14 intermediate and mistaken 15/16 observer are retained with hashes and excluded from acceptance.

Separate [18/18 modeled sequence checks](Activity-date-only/sequence.json) and [35/35 actual producer/Core actions](Activity-date-only/actions.json) pass on the final frozen build. Fresh strict TypeScript/build, unsigned native/NSIS build and 26 installer ownership checks pass. Memory/domain guards retain 8/7 negatives. The [47 host + 3 Core tests](Activity-runner-pipe/tests.json) are reused because their exact Rust source, Cargo files and pinned revision are unchanged; the proof records the host-source digest.
