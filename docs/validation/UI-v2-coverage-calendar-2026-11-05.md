## 产品与数据边界

时间工作区新增覆盖日历。独立 `coverage-fixtures.ts` 提供 3 个材料身份与 4 条记忆的当前采用状态；两条记忆共享同一材料，另有一个尚未形成记忆的材料。原 `fixture.ts` 未改，也不从摘录数量、trail、系统采用次数或复合展示状态反推材料和 adoption。

三层分别是收到的材料、暂存记忆、已采用记忆。材料按收到时间计数；记忆按可能的发生时间范围及当前采用状态计数，使用 Asia/Shanghai 日界线。月份与范围可以覆盖多天，因此日计数不能相加，不表示每天都发生或每天新采用；未知发生时间独立列出，不能用收到时间填补。计数口径随日历表头保留可见；图层均可关闭，关闭不是零。选择某日材料不会捏造记忆，点记忆继续用共享 Inspector。

原始及其他样本没有独立材料目录，覆盖不可统计，不画全零日历。显式链接打开覆盖样本与覆盖子视图，保留浏览器 URL 的语言/主题。原始 ID、revision 与时间只作为原样材料显示。没有发送、写入、轮询重发或真实服务调用。
