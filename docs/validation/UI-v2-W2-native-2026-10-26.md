# UI v2 W2 · 原生 WebView2 验证

2026-10-26（Asia/Shanghai）。代码基线 `4dc502b83276aa5bb7a6d94a4bcd5d7aa7d4e021`，即 PR #103 合并后的 `origin/main`；分支 `codex/ui-v2-w2-native-validation`。本片只记录观察，未修改前端、`src-tauri`、Memory pin 或领域代码。

## 环境与方法

使用仓库锁定的 Rust 1.98.1 GNU、Tauri 2.12.0、React 19.3.0、Vite 8.3.1，离线 `cargo build --locked --offline --manifest-path apps/desktop/src-tauri/Cargo.toml` 构建真实原生调试程序，加载当前 worktree 的 Vite 页面。构建时通过已有的 `TAURI_CONFIG` / `app.appDirectoriesOverride` 隔离应用目录；WebView2 使用独立 profile。DevTools 仅监听 loopback；连接前逐级核验监听 PID 是本次启动程序的后代。

尺寸测量与调整原样复用 `e2e/memory-smoke.mjs` 的 `ownedWindowMetrics`：每次核验窗口 PID/标题、读取 `GetDpiForWindow` 与 client rect，再调整自己的 HWND。未使用 CDP viewport/DPR 模拟。主题用 WebView2 的 `prefers-color-scheme` 媒体覆盖验证两套配色；这部分不等于 Windows 明暗设置切换验收。

通过 Windows 显示设置实际切换 150% → 125% → 100% → 150%，每档都记录原生 DPI 与页面 DPR；系统动画效果暂时关闭后恢复。未更改系统语言、登录启动、托盘或热键实现。测试传入的 `--hotkey-key F12` 不属于该实现支持的快捷键字符，观察为 unavailable；本片不验收 W7 热键。
