# UI v2 · 原生 Sessions 时间尺，2026-11-01

基线 `cde091c`（首页切片）；分支 `codex/native-home-time-structure`。Memory pin 未变，只有前端呈现和合成验证改动。

## 行为

- 事件顺序保持 Core 保存的顺序；有效相邻时间按每分钟 2px、最多 48px 增加间距。缺失/无效时间不连接推算，负间隔不画成正间隔。
- 时间尺用 UTC+8，`time[datetime]` 和 `title` 保留原始 ISO 字符串；元数据仍区分已保存事件种类与交付状态，原始正文不变。
- `checkpoint_created` 标记自己的事件并画括号；不推断检查点覆盖哪些事件，不把临时检查点说成已审阅记忆。
- 地图仅覆盖本次已读取的转录，不声明完整历史。只有全部时间有效且不倒序时借给原生记录带；不创建任何额外领域请求。
- 转录滚动更新地图窗口，地图 Home/End 等既有控制反向滚动转录；尺寸与展开内容变化会重新测量。减少动画时使用即时滚动。
- 读取中或失败时撤下地图，旧正文仍按原行为标为上次成功读取；切换会话和离开页面清理地图。现有草稿、写入阻塞、焦点与跨会话回执所有权不变。
