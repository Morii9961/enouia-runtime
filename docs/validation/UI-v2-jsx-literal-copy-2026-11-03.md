# UI v2 未经翻译的 JSX 文字与可访问名称

基线：`678f475`，分支 `codex/read2-synthetic-surface`。没有改 Rust、adapter、Memory pin 或数据形状。

## 问题

字典覆盖测试只统计 `t()` / `tn()` / `tj()` / `msg()` 标出的字符串，因此“0 missing”不能证明界面已全部翻译。直接写在 JSX 里的文字、字面量 `aria-label` / `title`，以及子表达式里的字面量（如 `cond ? 'yes' : 'no'`、`` `${n} units` ``），在中文、日文下仍显示英文。数字、名称和英文碎片拼在一起的句子也无法按目标语言调整语序。

## 新守卫

`tests/i18n.test.mjs` 新增一项检查，用 Vite 公开导出的 `parseSync`（oxc，无新依赖）解析 `src` 下每个 `.tsx` 文件，报告三类问题：

- 含 3 个以上连续英文字母的 `JSXText`；
- 字面量形式的 `aria-label` / `title` / `placeholder` / `alt`，包括模板字符串里的固定片段；
- 作为 JSX 子节点的表达式中的字符串字面量，涵盖条件、逻辑、`+` 拼接和括号表达式。

例外：元素或其祖先带 `lang="en"`、位于 `<code>` / `<kbd>` / `<samp>` 内，以及产品名 `Enouia Runtime`、`UTC+8`、`GiB`、`Ctrl+Alt+…` 按键名、`%APPDATA%` 路径和链接。守卫上线时报出 36 + 16 处，全部按下文处理后为 0。

## 修复

- 共用：表面错误回退说明、导入报告“原始导入”、Runtime 面板的 unknown / visible / hidden、Vault 状态行的 error / watermark。
- 演示屏：Context 的 胶囊 / 编译于 / 查询 / “已用 x / y 单位” / 模拟服务商读取行；Sessions 的轮次、检查点范围、间距说明和分钟间隔；Memory 的 conf / Related；Home 的演示会话标题标为 `lang="en"`（会话内容保持原文）。
- 自动记忆演示：关联视图标题、缩放、直接关系数和选中节点的可访问名称；形成视图的间隔天数和只读说明；召回实验室的五个站名（新增界面标签表，fixture 不改）、单位、上限、对象外数量、截断 yes / no；时间线标题、收到时间、滞后天数（`tn` 单复数）、前后计数和“如何形成”；Inspector 的时区说明和三个停用按钮；星图提示。

拼接句一律改成带占位符的整句模板，让译文自行安排语序。fixture 里的虚构记忆标题、陈述和步骤说明按 fixture 自身规则保持英文，没有翻译。

## 字形覆盖

新增中日文全部通过 `cjk-fonts`。标签子集缺的字改用已有措辞，字体包不变：中文避开「即」「均」「浏」「松」「供」「资」「水」，日文避开「他」「身」「ゾ」「触」「寄」「緒」「歩」「模」「擬」「隣」「非」。用语沿用已有翻译，例如日文「ターン {n}」、中文「模拟服务商」。
