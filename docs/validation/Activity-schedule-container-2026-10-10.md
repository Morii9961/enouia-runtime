# Schedule decoration without a worker panic

Date: 2026-10-10. Baseline: `26ee28116588cc86db6fce6386f321c7a75b487f`. This changes only the Activity host's schedule decoration boundary. Producer/store, wire schema, frontend, dependencies and Memory pin remain unchanged. J1/B4 remain partial and B5 is inactive.

Native IPC then rejected with `worker_failed`, so the client displayed a generic call failure. Null or missing schedules were silently converted into incomplete objects. The host now requires an object before writing its fields and otherwise returns the existing structured `contract_invalid` error. Complete DTO validation still belongs to the client.
