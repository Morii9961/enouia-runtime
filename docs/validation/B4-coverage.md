Run `node scripts/check-activity-evidence.mjs --self-test` from the repository root. The checker verifies all 18 unique rows, report hashes/states/counts, 152 evidence selectors, matching unit/zone literals, the ten unpublished C15 regression candidates, explicit row gaps and inactive B4/B5 gates. Twelve negative checks reject missing rows, changed report bytes, invented selectors, escaping paths, automatic acceptance/activation, missing gaps, duplicate reports, wrong classification authority, missing current C06/C17 links and stale current-report state. This is an offline documentation integrity check; it runs no collector, scheduler, network transport or reference checkout.
