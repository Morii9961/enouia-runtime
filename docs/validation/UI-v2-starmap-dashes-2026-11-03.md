# UI v2 #24 虚线假设对照

基线：`1688c6a`。在第一轮[成本定位](UI-v2-starmap-cost-2026-11-03.md)之后，工具增加 `--dashes` 模式：保留全部 4,300 条主题连线，对照原生虚线、临时实线和将同样 3px/3px 间距展开为独立路径的手工虚线。只在临时浏览器里替换 Canvas 方法，产品绘制代码不变。

命令沿用前轮，将输出改为 `target/starmap-dashes` 并追加 `--dashes`。浏览器和尺寸相同；每组 1.2 秒预热、6 秒采样，八组无隐藏/零样本。完整数据见[结果](UI-v2-starmap-dashes-2026-11-03.json)。此模式额外捕获路径几何，不与前轮的脚本耗时作绝对比较。

| 5,000 节点 | 原样前 | 临时实线 | 手工虚线 | 原样后 |
| --- | ---: | ---: | ---: | ---: |
| 球体 draw 间隔中位 ms | 192.1 | 122.5 | 147.3 | 143.0 |
| 聚类 draw 间隔中位 ms | 99.3 | 61.5 | 95.7 | 97.0 |

球体前后基线漂移明显，不据其第一组归因改善。聚类的稳定前后对照说明虚线参与成本，但改为实线仍慢于 35ms 的“省略主题线”对照。手工虚线没有足以解决问题的收益：其脚本 draw 从原样约 1.5ms 增至 4.2ms，draw 间隔仍约 96ms。

另将同一帧的 4,300 段坐标、色彩、宽度、透明度和 DPR 变换分别绘到两个透明画布，逐像素对照原生/手工虚线：球体 1,533,060 像素中 167 个不同，聚类 416 个不同；RGBA 通道平均差分别约 0.000414 和 0.000465。不能称为像素完全等价。未将手工虚线、实线或删线交付到产品，也未改既定视觉。

本片完成八组隔离浏览器实验、同几何像素对照、`node --check` 及 `git diff --check`，没有重跑产品测试或构建。探针结果是 draw 完成间隔，不是实际呈现帧；不是 WebView2、人类验收或已完成性能优化。#24 仍未关闭。
