## 实现与授权

更纱 300/400/600、M PLUS 可变 300–600 使用当前字典的 CJK 字符子集；中文正文按 IPA 派生规则更名 Enouia Text SC，100 片保留完整 27,687 个字符映射与原有 UVS；Zen 300/400/500/700 每字重保留 7,737 个映射、各 100 片。生成器保留 hinting/layout/licence metadata，并重新打开每个 WOFF2 验证覆盖、IPA 主名称与可变轴范围。M PLUS 缺少 U+FF0F/U+FF1A，明确由 Zen 承接。

完整许可随字体保存，并由 Settings 延后加载供阅读。原始 IPA 恢复入口要求用户自行从原发布方取得并通过 Windows 安装 IPAexGothic，之后选择该本机字体；未安装时明确报错并保留原选择。原始字体移除后的回退不包含派生字体。本机未安装 IPAexGothic，因此真实 WebView2 验证了缺失拒绝；成功选择/偏好保存/切回使用受控可用性模型验证，不声称完成真实原始字体安装验收。授权依据与来源见 [字体 README](../../apps/desktop/src/assets/fonts/README.md)。

## 渲染证据

使用 W3 的隔离原生调试壳加载当前 Vite 前端，真实 Memory 状态为无库；没有 native stub 或演示回退。CDP `CSS.getPlatformFontsForNode` 确认中文标题为自托管更纱、正文为 Enouia Text SC，日文为 M PLUS / Zen。标签字典以外的「龘」实际由 Enouia Text SC 绘制。中文禁止伪粗体。产品名与 Home 的 `I'm here.` 继续英文。

原生在 150% Windows DPI、1440×900 逻辑窗口，三语 × 两主题 × 六表面，共 36 张截图，页面横向溢出 0。独立无头 Edge 在 1440×900 下生成 48 张浏览器演示截图：三语 × 两主题 ×（六表面、自动记忆、独立 `/starmap.html`）。浏览器自动记忆与星图均为明确标注的虚构演示，没有放入 Runtime 原生壳。抽查中文 Memory、日文 Settings、中文自动记忆与日文星图原图，字体清晰、无缺字方框；覆盖范围是这些测试状态，不代表全部正文/Unicode 字符的人工审阅。

本机证据仅在忽略目录 `.design/w4/`：`shots/`、`native-matrix.json`、`browser-matrix.json`、`payload-final.json`、`native-matrix.log`。冷启动字体测量为无库 Home，不能代表任意数据页面的全部流量。未重跑 W2 的 100/125% 实机 DPI 矩阵；未使用个人 Vault、真实 Provider、安装或部署。
