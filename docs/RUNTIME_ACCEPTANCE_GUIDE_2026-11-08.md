# Runtime 桌面人工验收指南（候选 `128ae13`，2026-11-08）

这份指南给 Morii 照着做。界面名称按中文界面写，括号里是英文界面的对应文字。自动化已经覆盖的部分（[候选记录](validation/UI-v2-candidate-128ae13-2026-11-08.md)）不再重复；这里只列必须由人在真实 Windows 桌面上确认的事。每一项写明怎么做、应该看到什么、记录什么。不通过的项把现象、截图和时间告诉 Claude 或 Codex，按“先复现，再最小修复”处理。

## 准备

- **安装包**：`E:\Enouia Runtime\apps\desktop\target\candidate-128ae13\Enouia Runtime_0.1.0_x64-setup.exe`，22,541,585 B，SHA-256 `609f39115f9c3e8b91900f9684e7a152b0a60115901bdc1de8010807d1703925`。安装前可在 PowerShell 里用 `Get-FileHash` 核对。
- **环境**：建议用独立的 Windows 用户账户或虚拟机。安装是“当前用户”安装，会写开始菜单快捷方式；开启登录启动后会写 `HKCU\…\Run\EnouiaRuntime`。在日常账户上做也可以，但请在验收结束时按第 8 步还原。
- **数据**：建一个专门的测试 Vault，放在新建的空文件夹里（例如 `D:\EnouiaAcceptance\vault`）。本指南不需要个人 Vault；是否用个人资料验收由你另行决定。
- **热键**：默认 Ctrl+Alt+M 在当前这台机器上被占用（OPEN_ISSUES #28）。要么在没有冲突的环境里测，要么先记录冲突时的表现（第 4 步），默认键是否更换由你决定。
- **记录**：每一步记“通过 / 不通过 / 备注”，必要时截图。

## 步骤

### 1. 安装（#27）

1. 双击安装包。未签名，Windows 可能显示“Windows 已保护你的电脑”（SmartScreen）。记录是否出现；选“更多信息 → 仍要运行”。
2. 安装程序的语言选择里应有 简体中文 / English / 日本語。选一种完成安装（当前用户，无需管理员）。
3. 开始菜单里应有 Enouia Runtime，启动后主窗口打开。

记录：SmartScreen 表现、语言选择器、安装是否需要管理员、开始菜单项。

### 2. 首次启动与测试 Vault

1. 首次启动没有 Vault，记忆页显示连接界面。选“新建记忆库…”（Create Vault…），选“准备”里新建的空文件夹。
2. 右上角状态徽标应显示记忆库已打开（英文界面为 “MEMORY · VAULT OPEN”）。
3. 在设置里切换三种语言和主题（跟随系统 / 黛蓝 / 宣纸），界面随之变化。

### 3. 托盘（#25）

1. 点主窗口右上角关闭，窗口应隐藏到托盘，进程继续运行（设置里有说明：关闭只是隐藏到托盘）。
2. 右键托盘图标，菜单应有：显示 Enouia Runtime、锁定记忆库、快速检索、退出 Enouia Runtime。切换界面语言后，菜单文字应跟着变。
3. 逐个点：显示主窗口；锁定后记忆页应要求解锁；快速检索打开搜索小窗；退出后进程结束。

### 4. 快捷键（#26 / #28）

1. 在主窗口以外的地方按 Ctrl+Alt+M，应弹出快速检索小窗，输入框获得焦点；按 Esc 关闭。
2. 如果快捷键被别的程序占用，界面应明确提示快捷键已被使用，并可改用托盘或按钮打开快速检索。记录占用它的程序（如果知道）。

### 5. 登录启动

1. 设置 → “窗口与启动”（Window and startup）→ 打开“登录时启动”（Start at login）。说明文字应写明默认关闭、只启动托盘、不打开 Vault。
2. 注销后重新登录：托盘里应出现 Enouia Runtime，主窗口不自动弹出，Vault 不会被自动打开。
3. 验收结束后在设置里关闭“登录时启动”。

### 6. 日常流程（测试 Vault 内）

1. 记忆 → 候选收件箱 → “记住一件事”（Remember something），写一句测试陈述并填一个 claim key，点“保存为候选”（Save as candidate）。
2. 在候选卡片上点“接受…”，或改一下内容再点“编辑后接受…”。确认对话框里应列出这次写入的全部记录和确认码，点带确认码的确认按钮。
3. 回到“当前记忆”，应看到刚批准的记忆；点开后右侧显示来源与证据；用左上搜索框按字面搜索能找到它。
4. 会话 → “新会话” → 提一个与这句陈述相关的问题 → 发送。本地 Mock 只引用已批准的记忆，回答里应能看到这条记忆。
5. 上下文 → 在输入框里写一个相关问题 → 预览。预览里应包含相关记忆。
6. 试一次纠正和遗忘：在记忆详情里写纠正内容后点“提出纠正”（会变成新候选，不直接改写原记忆）；点“删除影响”先看影响范围，再用“遗忘…”，同样要在确认对话框里确认。

### 7. 无障碍与高对比度

1. Windows 设置 → 辅助功能 → 对比度主题，打开任意一个高对比度主题。
2. 回到 Runtime，按 Tab 在顶部导航之间移动：当前页用内侧的系统高亮框标出，键盘焦点框画在按钮**外侧**，两者不重合（这是 2026-11-08 刚修的问题）。
3. 可选：用“讲述人”读一遍主导航、记忆列表和确认对话框，按钮都应有名字。验收后把对比度主题关掉。

### 8. 重装、卸载与还原

1. 再运行一次同一个安装包（同版本重装应被允许），测试 Vault 与设置应保留。
2. 从“设置 → 应用”卸载 Enouia Runtime。按 ADR-027，卸载不删除 Vault、备份或 WebView2 配置，只删除程序本身和 Runtime 自己的登录启动项。确认测试 Vault 文件夹仍在。
3. 不再需要时手动删除测试 Vault 文件夹。
